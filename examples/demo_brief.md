# Учебный пример: сервис Айя

Айя помогает собрать презентацию из текстового брифа и одного загруженного PPTX-шаблона.
Система сначала анализирует новый шаблон, а затем строит содержание презентации.
Один запуск создаёт три варианта с одинаковыми фактами и разной композицией.
Основной результат сохраняется в формате PowerPoint с редактируемым текстом.
Дополнительные результаты включают PDF и автономную HTML-версию.
Для каждого слайда сохраняются ссылки на исходные тезисы пользователя.
Автоматическая проверка отмечает текст, который может выйти за границы слайда.
Пользователь может выбрать замечания и запустить исправление выбранных объектов.
Предыдущая версия презентации остаётся доступной после исправления.
Модельные вызовы происходят на сервере; API-ключ не передаётся браузеру.
Все модельные роли работают через один серверный шлюз OpenRouter.
Время подготовки шаблона и время генерации трёх вариантов измеряются отдельно.
